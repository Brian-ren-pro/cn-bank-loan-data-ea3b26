# 中国银行贷款数据：来源、字段、处理步骤与相关文献

在线浏览：https://brian-ren-pro.github.io/cn-bank-loan-data-ea3b26/

纯静态网页，介绍中国企业银行贷款数据的三类来源（A 股上市公司、新三板挂牌公司、银行），
每类数据有哪些字段、怎样从年报与公告整理成面板、变量怎么构造，以及相关文献的做法。

- `index.html`：页面与内容
- `data/`：字段统计（由原始数据生成）
- `assets/`、`figs/`：原文截图与图表

本仓库只放网页，不含任何原始数据或整理后的数据文件。页面由内部项目自动生成，请勿直接修改。
