# 中国银行贷款数据 · 数据来源网页

纯静态网页：从总览点进每个板块，看原文截图、每张数据表的全部字段、从原始表到分析面板的处理步骤、数据概述和相关顶刊文献。

## 打开方式

直接双击 `index.html`（不需要服务器、不需要联网）。如果浏览器限制本地文件，在终端运行：

```bash
cd "Bank/doc/组会汇报_20261029/网页" && python3 -m http.server 8765
```

然后打开 http://127.0.0.1:8765 。

## 页面

- **总览** `#/`：三类来源（A 股、新三板、银行）× 两种载体的树；六类数据的字段对比表；三个常见误读。
- **六个板块**，每个分四段：原始数据来源 / 面板数据处理 / 数据概述 / 相关顶刊文献。
  - `#/a-annual` A 股 · 年报与半年报附注 —— CSMAR 借款统计表（半年度）25 个字段＋处理步骤；文献拆解：李广子、刘力 2020
  - `#/a-ann` A 股 · 临时公告 —— CSMAR 借款表（日）43 个字段＋处理步骤；CNRDS 银行借款 8 个字段；文献拆解：王怀明、王思远 2026
  - `#/n-annual` 新三板 · 年报与半年报附注 —— 我们的三套数据：企业—年分类汇总（44＋41 个字段）、逐笔贷款（29 个字段，清洗漏斗）、企业×银行（8 个字段）；文献拆解：武龙 2019
  - `#/n-ann` 新三板 · 临时公告 —— 检索证据与 A 股对照
  - `#/bank-annual` 银行 · 年报与财务数据库 —— 600 多家商业银行数据 12 张表一览，贷款分析等 4 张表的全部字段（对上 CSMAR 银行库代码与说明）；文献拆解：李逸飞等 2022
  - `#/bank` 银行 · 内部数据 —— 四篇文献的字段对照；文献拆解：曹廷求、庞念伟 2025
- **变量构造手册** `#/vars`：七组贷款变量（规模、成本、担保结构、特定类型、逐笔、企业×银行、银行—年）的公式、字段、文献与注意事项；12 条通用处理规则。

## 更新字段统计

字段说明、有值比例、取值分布和处理步骤的计数都来自原始数据，重跑：

```bash
python3 Bank/code/20261102_O_网页字段字典.py
```

脚本读 Task9 下的 CSMAR 借款表（日、半年度）及其官方 [DES] 字段说明、600 多家商业银行数据、CSMAR 银行库字段字典，以及本项目 `Bank/data` 下的企业年度面板、变量面板、逐笔试点、企业×银行表；在 worktree 里运行时自动到主目录找数据。核对用的摘要写到 `Bank/data/网页字段字典_20261102/网页字段字典_20261102.md`。

## 改内容

- 文献：`const P`（题目、作者、期刊、年份、摘要、数据来源）、`FD`（字段与用法）、`ST`（贷款变量描述统计）。
- 板块：`const S`。每个板块的 `tables` 决定“面板数据处理”里显示哪些表；`USE`、`KEY` 给出各表常用字段及用法。
- 变量手册：`const VG`（变量表）、`RULES`（处理规则）。
- 首页对比表：`const CMP`。

## 文案约定

- 各板块四段固定叫：原始数据来源 / 面板数据处理 / 数据概述 / 相关顶刊文献。
- 文字直白，少用小字注解；图注写文件、行数和内容。
